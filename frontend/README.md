# Weave Frontend

Next.js 16 (React 19) 기반 프론트엔드.

## 개발 환경

프로젝트 루트에서 `make up-build`로 전체 서비스를 실행하는 것을 권장합니다.
프론트엔드만 단독 실행하려면:

```bash
npm install
npm run dev
```

## 주요 기술

- **Next.js 16** (Pages Router)
- **React 19**
- **SCSS** (BEM + CSS Variables 테마)
- **TipTap** — 리치 텍스트 에디터 (Canvas)
- **Yjs** — 실시간 협업 (WebSocket)
- **dnd-kit** — 드래그 앤 드롭
- **axios** — API 통신
